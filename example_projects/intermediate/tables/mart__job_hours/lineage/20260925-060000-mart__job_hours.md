## write_job_hours

It writes the whole Saved table mart.job_hours.

- Reads: ops.job_events, ops.job_owners
- Writes: mart.job_hours

### Hive as submitted

```sql
WITH job_events AS (
  SELECT
    job_events.job_id,
    job_events.event_type,
    job_events.dt,
    job_events.minutes / 60 AS hours
  FROM ops.job_events AS job_events
), run_hours AS (
  SELECT
    e.job_id,
    o.team,
    e.hours
  FROM job_events AS e
  LEFT JOIN ops.job_owners AS o
    ON e.job_id = o.job_id AND e.dt = o.dt
  WHERE
    e.event_type = 'finish'
)
INSERT OVERWRITE TABLE mart.job_hours
SELECT
  run_hours.job_id,
  run_hours.team,
  SUM(run_hours.hours) AS sum_of_hours
FROM run_hours
GROUP BY
  run_hours.job_id,
  run_hours.team
```

### Calculated columns

Every column that is calculated rather than copied, in the order it is calculated.

#### `job_events.hours`

Calculated in **job_events** as `job_events.minutes / 60`.

```text
job_events.hours = job_events.minutes / 60
└─ ops.job_events.minutes  (int)
```

#### `sum_of_hours`

Calculated in **write_job_hours** as `sum_of(run_hours.hours)`, which is `SUM(run_hours.hours)`.

```text
write_job_hours.sum_of_hours = sum_of(run_hours.hours)
└─ run_hours.hours
   └─ job_events.hours = job_events.minutes / 60
      └─ ops.job_events.minutes  (int)
```

Rows that count:

- WHERE in run_hours: `equals(e.event_type, "finish")`, which is `e.event_type = 'finish'` (reads ops.job_events.event_type)

One value for each different `run_hours.job_id` and `run_hours.team`.

### Copied columns

- `job_id` comes from run_hours.job_id ← job_events.job_id ← ops.job_events.job_id
- `team` comes from run_hours.team ← ops.job_owners.team
