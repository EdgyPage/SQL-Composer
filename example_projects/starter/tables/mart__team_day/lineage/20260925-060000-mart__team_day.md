## write_daily_job_runs

It writes the Saved table mart.daily_job_runs, replacing each partition its rows fill.

- Reads: ops.job_runs
- Writes: mart.daily_job_runs
- Session settings dynamic_partitions, sent before it: SET hive.exec.dynamic.partition=true; SET hive.exec.dynamic.partition.mode=nonstrict

### Hive as submitted

```sql
WITH runs_per_job AS (
  SELECT
    job_runs.job_id,
    job_runs.dt,
    COUNT(*) AS runs,
    COUNT(CASE WHEN job_runs.status = 'FAILED' THEN 1 END) AS failed_runs,
    SUM(job_runs.duration_mins) AS minutes
  FROM ops.job_runs AS job_runs
  WHERE
    job_runs.dt = '2026-09-24'
  GROUP BY
    job_runs.job_id,
    job_runs.dt
)
INSERT OVERWRITE TABLE mart.daily_job_runs PARTITION(dt)
SELECT
  runs_per_job.job_id,
  runs_per_job.runs,
  runs_per_job.failed_runs,
  runs_per_job.minutes,
  runs_per_job.dt
FROM runs_per_job
```

## write_team_day

It reads the Saved table mart.daily_job_runs, written by write_daily_job_runs above. It writes the Saved table mart.team_day, replacing each partition its rows fill.

- Reads: mart.daily_job_runs, ops.jobs
- Writes: mart.team_day
- Session settings dynamic_partitions, sent before it: SET hive.exec.dynamic.partition=true; SET hive.exec.dynamic.partition.mode=nonstrict

### Hive as submitted

```sql
INSERT OVERWRITE TABLE mart.team_day PARTITION(dt)
SELECT
  jobs.team,
  SUM(daily_job_runs.runs) AS runs,
  SUM(daily_job_runs.failed_runs) AS failed_runs,
  SUM(daily_job_runs.minutes) AS minutes,
  daily_job_runs.dt
FROM mart.daily_job_runs AS daily_job_runs
JOIN ops.jobs AS jobs
  ON jobs.job_id = daily_job_runs.job_id
WHERE
  daily_job_runs.dt = '2026-09-24'
GROUP BY
  jobs.team,
  daily_job_runs.dt
```
