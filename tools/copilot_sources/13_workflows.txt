## Terms

- **Workflow**: ordered steps to one end goal; each step is a cell of its notebook,
  admin/workflows/<name>/<name>.ipynb. Its **names cell** holds its inputs in capitals.
- **Decision**: one thing about one table only the user decides, such as its location, Key
  or a column type, answered in the **decisions cell**, DECISIONS.
- **Saved table**: a table the user's own code writes; its **Table reference** is the file
  of its columns, partitions, Key and location.
- **DEV**, **PROD**: the Dev Database, where tables are built and compared, and the Prod
  Database, where others read them; set once in admin/databases.py.

## How a Workflow runs

- DECISIONS holds each answer by the table's name as `project.check()` writes it:
  `{"mart_dev.weekly": {"location": "/data/team/mart_dev.db/weekly", "key": ["job_id"],
  "types": {"fails": "bigint"}}}`; write_decisions writes them.
- The last cell, `project.run_workflow(...)`, runs every step left, up to the first only the
  user can do; `dry_run=True` sends nothing.

## convert: someone else's Hive into Saved tables in dev

Its inputs:

- NAME: the batch's name (for the last cell alone, a list of batches converted already).
- FILES: the .hql files, saved in admin/workflows/convert/; or `FILES = []` and HIVE the
  Hive as text. A query alone makes a Saved table too, named for its file or NAME.
- DATABASE: the database of a table the Hive names without one, such as "ops".
- RENAME: a dev copy's own name, with no database, by the table's full name (DATABASE when
  the scripts give none): `{"mart.team_fails": "team_fails"}` makes mart_dev.team_fails.
  Left `{}`, it is <table>_<its database>: team_fails_mart.
- STAGING: each staging table convert's report names, made by one statement, read by a later
  one: "fold", as `{"ops_reports.failed": "fold"}`, puts its query in each table reading it;
  "keep" makes it a Saved table. Left out: folded if temporary or DROPped, else kept.

{workflow: convert}

## promote: dev tables to prod

TABLES are the dev tables, such as ["mart_dev.daily_job_runs"].

{workflow: promote}
