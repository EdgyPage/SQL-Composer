## Patterns: when the Hive says X, write Y

| ID | The Hive says | Write |
|---|---|---|
| P1 | `FROM ops.job_runs r` | `r = AS(job_runs, "r")`, then `r.status` |
| P2 | `WITH ev AS (SELECT ...)`, `FROM (SELECT ...) ev` | `ev = derived("ev", statement(...))` |
| P3 | `a = 'x' AND b > 3` | `WHERE(equals(t.a, "x"), more_than(t.b, 3))` |
| P4 | `OR`, `IS NULL`, `<>`, `BETWEEN` | `any_of`, `is_null`, `not_equals`, `between` |
| P5 | `IN ('a', 'b', 'c', 'd')` | `STATUS_VALUES = [...]`, `is_in(t.status, STATUS_VALUES)` |

| P7 | `SUM`, `AVG`, `MIN`, `MAX` | `sum_of`, `average_of`, `min_of`, `max_of`, with AS |
| P8 | `SUM(CASE WHEN c THEN 1 ELSE 0 END)` | `sum_of(if_else(c, 1, 0))` |
| P9 | `COALESCE(x, 0)` | `fill_null(t.x, 0)` |
| P10 | `CASE x WHEN 'a' THEN 'A' ... ELSE 'O' END` | `mapped(t.x, {"a": "A"}, otherwise="O")` |
| P11 | `CASE WHEN c1 THEN v1 ... ELSE v END` | `first_match([(c1, v1)], otherwise=v)` |
| P12 | `LEFT JOIN t ON ... AND t.dt = 'd'` | `equals(t.dt, "d")` kept in ON=, `all_of` |
| P13 | `UPPER(x)`, a function not wrapped | `hive_function("upper", t.x)` |
| P14 | anything else, as `x DIV 60` | `unchecked_column("{m} DIV 60", m=t.minutes)` |
| P15 | `ROW_NUMBER() OVER (PARTITION BY a ORDER BY b DESC)` | `row_number(...)`, file 05 |
| P16 | `SET k=v;` | `hive_settings("converted", sets={"converted": {"k": "v"}})` |
| P17 | `INSERT OVERWRITE TABLE ... SELECT` | the SELECT; the write is file 06's |
| P18 | `<PARM="NAME"/>`, a Script tag | R6 to R8 |

## Terms

- **Saved table**: a table of the user's own; `project.convert` makes one of each table the
  Hive writes, in the Dev Database, with its Decisions, what only the user decides.
- **Script tag**: `<PARM="NAME"/>` in the Hive, which the old scheduler filled in.

## Rules

- **R1** Asked for Toolbox code, piece by piece or not: write it by hand, as W1, one
  Statement `s`. Asked to make the Hive into tables in their Project: file 13's convert
  Workflow, `project.convert("weekly_events", HIVE, query=query)`.
- **R2** Keep the Hive's columns: same names, same order; each short table name kept with
  AS; each condition there, none added. Keep a CTE's or subquery's name after the bracket.
- **R3** Hive reading a partitioned table whole: say so; `reads_all_partitions=True` only if
  the user wants every day.
- **R4** Compare on one day, once written: `compare_with_original(s, HIVE, query=query,
  partition={"dt": "2026-09-24"})`.
- **R5** In a Project, `project.load("mart_dev.weekly_events").preview()` gives a
  converted table's Statement; `project.check()` notes each `# CONVERSION:` mark.
- **R6** A Script tag whose value the user gives: `TAGS = {"NAME": "'2026-09-24'"}` written
  above the Statement, not imported, its value text; a bare tag's value keeps its own quotes,
  a tag inside quotes has none: `"FAILED"`. A bare tag is `script_tag(TAGS["NAME"])`, a
  quoted one `tag_text(TAGS["NAME"])`. Their old scheduler filling it in changes nothing.
  If they give no value, ask; never guess it.
- **R7** A value worked out each time the Hive is built, such as the latest Partition a
  table holds: a Run value, the value a function of theirs gives (file 17).
- **R8** Only if the user asks for a Hivevar, `${hivevar:NAME}` left for their scheduler:
  `hivevar("NAME", default="'2026-09-24'")`, imported.
- **R9** Each table's kind is a Decision (file 13): `"kind": "history"` if each write keeps
  the rows there, as `PARTITION (dt = ...)` or INSERT INTO; `"rebuilt"` if it replaces the
  table; `"proposed"` accepts it.

## Worked patterns

### W1: a query with a short name, an IN list and a count

`SELECT e.job_id, COUNT(*) AS events FROM ops.job_events e WHERE e.dt = '2026-09-24'
AND e.event_type IN ('start', 'finish', 'retry', 'fail') GROUP BY e.job_id`

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, SELECT, WHERE, count_rows, equals, is_in,
                              statement)
from references.ops__job_events import job_events

EVENT_TYPE_VALUES = ["start", "finish", "retry", "fail"]

e = AS(job_events, "e")
s = statement(
    SELECT(e.job_id, AS(count_rows(), "events")),
    FROM(e),
    WHERE(equals(e.dt, "2026-09-24"), is_in(e.event_type, EVENT_TYPE_VALUES)),
    GROUP_BY(e.job_id),
)
```
