# Copilot file 12: Power Query into Hive ({version})

**Use this file as reference while you follow file 15's steps: find each Power Query step
in Patterns, then write the Hive its rule gives.**

Objective: write each Power Query of an Excel workbook as the Hive that gives the same rows.
Load this file when the user attaches a workbook and asks for its calculations as Hive, with
file 15 (the steps, the map and the reply), file 11 (formulas), for a total file 23, and for
a PivotTable file 20.

## Patterns: when the workbook has X, look up Y

| ID | The workbook has | Rules |
|---|---|---|
| P1 | `Excel.CurrentWorkbook()`, another query's name | Q1 |
| P2 | Table.SelectRows, `<>`, null, Text.Contains, List.Contains | Q2 to Q4 |
| P3 | Select, Remove, Rename, Reorder, AddColumn, ReplaceValue | Q5, Q6 |
| P4 | Text., Number., Date. functions | Q7 |

## Terms

- **M**: Power Query's language: a `let` of named steps, each reading the one before; `in`
  names the one it gives.
- A step no rule here lists is refused: NULL in each column it makes, or the query left out,
  named with why.

## Rules: reading a table and its rows

- **Q1** `Excel.CurrentWorkbook(){[Name="t"]}[Content]` reads Table t, as `<database>.t`.
  Another query's name, as in `Table.Sort(q, ...)`, reads query q: a CTE, `WITH q AS
  (...)`, after each CTE q reads: a query, then the Table it loads, then a formula column
  reading that Table. `#date(2026, 9, 1)`: '2026-09-01'.
- **Q2** Table.SelectRows: WHERE; after a Table.Group, HAVING, repeating the aggregate. M's
  `<>` keeps a null, as Hive's doesn't: `(status <> 'TEST' OR status IS NULL)`; two columns:
  `(a <> b OR (a IS NULL) <> (b IS NULL))`. `=` between two columns: `(a = b OR (a IS NULL
  AND b IS NULL))`. `[c] = null`: `c IS NULL`; `[c] <> null`: `c IS NOT NULL`.
- **Q3** Text.Contains([c], "x"), Text.StartsWith, Text.EndsWith: `c LIKE '%x%'`, `'x%'`,
  `'%x'`, case kept, as M keeps it. `not`: NOT.
- **Q4** List.Contains({1, 3}, [c]): `c IN (1, 3)`. List.Contains(u[k], [k]), a row whose k
  is in another table: `LEFT SEMI JOIN u ON u.k = t.k`; with `not`, G2's LeftAnti.
- **Q5** Table.SelectColumns, RemoveColumns, RenameColumns, ReorderColumns: the SELECT list,
  in the last step's order; Table.DuplicateColumn(t, "c", "d"): `c, c AS d`.
  TransformColumnTypes, Table.Buffer, Table.PromoteHeaders: nothing. Excel's step names,
  such as "Changed Type", are only names: read the function each step calls.
- **Q6** Table.AddColumn: an expression AS its name, `if c then a else b` as IF(c, a, b).
  Table.TransformColumns(t, {{"c", Text.Upper}}): UPPER(c) AS c. Table.ReplaceValue(t, null,
  0, Replacer.ReplaceValue, {"c"}): COALESCE(c, 0) AS c; with "x", "y" and
  Replacer.ReplaceText: REPLACE(c, 'x', 'y') AS c; with Replacer.ReplaceValue and a value:
  `IF(c = 'x', 'y', c) AS c`, the whole cell matched.
- **Q7** As their twins in file 11: Text.Upper, Text.Lower, Text.Trim, Text.Length;
  Text.Start(x, n): SUBSTR(x, 1, n); Text.End(x, n): SUBSTR(x, -n); Text.Middle(x, s, n):
  SUBSTR(x, s + 1, n), as M counts from 0; Text.Replace: REPLACE; Text.Proper: INITCAP;
  Text.Combine({a, b}, ","): CONCAT_WS(',', a, b); Number.Round: BROUND, as M rounds a half
  to even; Number.RoundDown, RoundUp: FLOOR, CEIL; Number.Abs: ABS; Number.Mod: PMOD;
  Date.Year, Date.Month, Date.Day; Date.AddDays: DATE_ADD; Date.AddMonths: ADD_MONTHS;
  Date.AddYears(d, n): ADD_MONTHS(d, 12 * n); Date.EndOfMonth: LAST_DAY;
  Date.StartOfMonth: `CAST(TRUNC(d, 'MM') AS STRING)`.

## Rules: grouping, joining, stacking

- **G1** Table.Group: GROUP BY, Table.RowCount(_) as COUNT(*), List.Sum, List.Max, List.Min,
  List.Average as SUM, MAX, MIN, AVG, List.StandardDeviation as STDDEV_SAMP.
  List.Count(List.Distinct([c])): COUNT(DISTINCT c), which leaves out NULL where M counts it:
  name it where c has a blank in the sample.
- **G2** NestedJoin then ExpandTableColumn, by JoinKind: LeftOuter: LEFT JOIN; Inner: JOIN;
  RightOuter: LEFT JOIN, the tables swapped; FullOuter: FULL OUTER JOIN; LeftAnti: `LEFT
  JOIN u ON t.k = u.k WHERE u.k IS NULL`, t's columns only; RightAnti: the same, swapped.
  ExpandTableColumn's fourth argument, new names: AS.
- **G3** A NestedJoin on every column, its new column removed, in Table.Distinct: Inner is
  `INTERSECT`, LeftAnti is `EXCEPT`. Table.AddColumn(t, "u", each u), expanded: `CROSS JOIN
  u`.
- **G4** Table.Combine: UNION ALL, columns matched by name, NULL where missing; inside
  Table.Distinct, UNION. Table.Distinct alone: SELECT DISTINCT.
- **G5** Table.Unpivot(t, {"a", "b"}, "measure", "amount") or UnpivotOtherColumns: one SELECT
  per column, stacked with UNION ALL, `'a' AS measure, a AS amount` after the kept columns,
  each `WHERE a IS NOT NULL`, as M drops a null there.

## Rules: sorting

- **S1** Table.Sort then FirstN: ORDER BY ... LIMIT, Order.Descending as DESC. FirstN alone:
  LIMIT.
- **S2** Table.AddIndexColumn(t, "n", 1, 1) after a Table.Sort: `ROW_NUMBER() OVER (ORDER BY
  ...) AS n`; inside a Table.Group's `each`, PARTITION BY its keys. From s by k:
  `(ROW_NUMBER() OVER (..) - 1) * k + s`; none given, 0.
- **S3** A Table.Sort with no FirstN or index after it: no ORDER BY, as a Hive table holds no
  order; mark "order dropped".

## Rules: marks, refused

- **M1** Sql.Database or a source outside the workbook: read the table it names; mark
  "Sql.Database".
- **M2** Table.Pivot: a `SUM(CASE WHEN severity = 'high' THEN 1 END) AS high` column per value
  in the sample, THEN 1 to count, THEN v to add up v, NULL where none; mark "pivot": its
  columns are now fixed.
- **X1** Refused, and named: Web.Contents or any web source (that query left out); a native
  `[Query=..]`; Table.AddIndexColumn with no Sort before it; Table.FillDown and FillUp;
  Table.Distinct with a column list; List.Median.

## Worked patterns

### W1: a query to filter, group, keep groups over one

Table job_runs (run_id, job_id, status, duration_mins); query busy_jobs loads busy_jobs:

    let
      Source = Excel.CurrentWorkbook(){[Name="job_runs"]}[Content],
      Ok = Table.SelectRows(Source, each [status] <> null
        and Text.StartsWith([status], "SUCC")),
      Grouped = Table.Group(Ok, {"job_id"}, {{"runs", each Table.RowCount(_)}}),
      Busy = Table.SelectRows(Grouped, each [runs] > 1)
    in
      Busy

Map: Sources job_runs. Finals busy_jobs (job_id, runs).

```sql
SELECT job_id, COUNT(*) AS runs FROM <database>.job_runs
WHERE status IS NOT NULL AND status LIKE 'SUCC%'
GROUP BY job_id HAVING COUNT(*) > 1
```
