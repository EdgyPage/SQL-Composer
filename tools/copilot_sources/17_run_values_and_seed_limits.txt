# Copilot file 17: Run values, answers for every table, and seed limits ({version})

**Follow the steps below in order, as written, adding none; reply as Output says.**

Objective: write a Run value, a function of the user's that works out a value each time a
table is written, and the decisions cell answers that use it: a Script tag's, one for every
table, and a seed's limits. Load this file when the user wants a tag's day worked out at
each run, one answer for every table, or a seed of only some Partitions. File 13 is for the convert
Workflow's other steps, file 16 for promote's.

## Terms

- **Script tag**: a `<PARM="NAME"/>` in Hive someone else wrote, which the program that ran it
  filled in; a Conversion leaves each as a Decision of its table, under "tags".
- **Decision**: one thing about one table only the user decides, answered in a Workflow
  notebook's **decisions cell**, DECISIONS; the answers' step (step 3; new_table's step 5)
  writes each answer into the table's **Table reference**, the file of its columns,
  partitions, Key and TAGS.
- **Run value**: what a function gives each time a Statement is built, written into the Hive as
  plain text: a `datetime.date` as '2026-09-24', a number as it is, True or False as TRUE or
  FALSE, text as Hive.
- **Partition**: the rows of a table that share one value of each partition column, such as dt.
- **Seed**: the one copy of the original's rows into a converted table that reads itself,
  before its first write: step 5 of convert, and of promote.

## Names for this objective, with their arguments

{names: project.new_run_value, latest_partition, today, hive_date, run_value, tag_text, project.write_decisions, project.register}

## Steps

1. **Pick the pieces**, the function, the answers or both, by the Decision rules. Done when
   each piece asked for is named. Then step 2.
2. **Write the function**, if one is asked for and the user hasn't one: for a table's
   latest Partition, the `project.new_run_value` call at the top of the decisions cell; for
   any other, by hand in building_blocks/run_values.py, importing `query` from warehouse; a
   tag's function takes no argument. Done when it gives a value. Then step 3.
3. **Write the decisions cell**: the function's import, then DECISIONS, then the notebook's
   answers' step cell, which writes them in. Done when each answer is in. Then step 4.
4. **Name the rest** in words, as Output says. Then step 5.
5. **Check** by the Self-check; fix what it finds, then reply.

## Decision rules

- If a tag stands for a day that changes each run, answer it with a Run value. If the user
  gives one fixed day, answer with text, as file 13 says.
- If the day is the newest Partition of a table:
  `project.new_run_value("period_end", latest_partition="ops.job_runs.dt")` writes
  `latest_partition(job_runs.dt, query)`, which reads no row, and registers the file. If it
  is today where the warehouse is: `today()` in UTC, or
  `today(utc_offset_hours=-6)` six hours behind it, the user's offset; yesterday is that minus
  `datetime.timedelta(days=1)`.
- If no Partition names it, the function runs a Statement of its own with run_query, each
  partitioned read bounded (file 03), and gives the value it read.
- Answer with the function's name, no brackets: `{"tags": {"PERIOD_END": period_end}}`. With
  brackets it is one day, which the answers' step leaves unwritten.
- The function lives in a file of the Project: one made in a notebook cell, a lambda or a
  nested one is left unwritten by the answers' step.
- If several tables share an answer, give it under "all_tables": "tags",
  "seed", or `"key": "proposed"`, which accepts each table's proposed Key. A table's own
  answer overwrites it, kind by kind and tag by tag. Any other Key, and a type, goes under
  each table, never "all_tables".
- A location is placed under "location_root" in admin/databases.py, never answered under
  "all_tables", which refuses it.
- If a table that reads itself needs only some Partitions, answer "seed", by partition
  column: a value, **that value or later**, never it alone; `{"from": ..., "to": ...}`, either end left out as
  the user likes; a list, those values alone; numbers as numbers. Any value may be a Run
  value's function. A column left out is copied whole; a column that isn't a partition column
  is refused. With no "seed", every Partition is copied. Under "all_tables", a limit applies
  only to the tables with that column.
- If the value goes in a Statement the user writes: `run_value(function, *arguments)`. In
  Hive written by hand (file 10): `hive_date(day)`, '2026-09-24' in quotes.
- If the table was converted before 8.4, its seed copies everything, as the Upgrade's mark
  says: say to convert its scripts again for a seed limit. Its tags take a Run value as 8.4's.

## Output

1. building_blocks/run_values.py in a ```python block, if step 2 wrote it.
2. The decisions cell, then the answers' step cell, in one ```python block.

## Examples

The latest day ops.job_runs holds, for PERIOD_END:

```python
"""Run values: what a Script tag stands for, worked out each time a table is written."""

import datetime

from sqlglot_composer import latest_partition
from references.ops__job_runs import job_runs
from warehouse import query


def period_end() -> datetime.date:
    """The latest day ops.job_runs holds."""
    return latest_partition(job_runs.dt, query)
```

The latest day a run succeeded, from a Statement of its own, its read bounded by the newest
Partition (lineage draws an arrow from ops.job_runs into the Run value):

```python
import datetime

from sqlglot_composer import (AS, FROM, SELECT, WHERE, at_least, equals, latest_partition,
                              max_of, run_query, statement)
from references.ops__job_runs import job_runs
from warehouse import query


def last_good_day() -> datetime.date:
    """The latest day a run succeeded, of the last 30 days ops.job_runs holds."""
    first = str(latest_partition(job_runs.dt, query) - datetime.timedelta(days=30))
    rows = run_query(statement(SELECT(AS(max_of(job_runs.dt), "day")), FROM(job_runs),
                               WHERE(at_least(job_runs.dt, first),
                                     equals(job_runs.status, "SUCCESS"))), query)
    return datetime.date.fromisoformat(rows["day"][0])
```
