# Copilot file 06: saving a table ({version})

**Find the request in Patterns, copy the worked pattern it names, change only the tables,

Objective: write a Saved table from a Statement, in its Table notebook. Load this file to
save rows into the user's own table, a day of it or more, or to write a logic cell.

## Patterns: when the user says X, do Y

| ID | The user says | Do | Copy |
|---|---|---|---|
| P1 | "write ... into my Saved table, replacing that day" | `INSERT_OVERWRITE(t)` first | W1 |
| P2 | "add ... to it, keeping what it holds" | `INSERT_INTO(t)` first | R2 |
| P3 | "write the Partition dt = D" | `INSERT_OVERWRITE(t, partition={"dt": D})` | R3 |
| P4 | a table with a Key | one row per Key | R4 |

| P8 | "send it myself, now" | create, Session setting, write | R8 |
| P9 | "show me first", "preview" | `show_hive(...)`, `run_query(preview(), query)` | R9 |
| P10 | "make its notebook", "the Hive in a file" | file 14; the `export_hive()` cell | R10 |

## Terms

- **Saved table**: a table of the user's that a Statement writes, described by its Table
  reference (file 02).
- **Partition**: the rows sharing one value of each partition column. **Key**: the columns
  whose values name one row.
- **Table notebook**: tables/<db>__<table>/<db>__<table>.ipynb; its **logic cell**, first
  line `# logic`, holds only imports, constants and functions.
- **Session setting**: a Hive SET a write may need first, from `hive_settings(...)`.

## Rules

- **R1** A write's SELECT gives exactly the table's columns, by name, in order, the
  partition column last; each calculation is named after its column:
  `AS(count_rows(), "runs")`.
- **R2** Each Partition the rows hold replaced: INSERT_OVERWRITE. Rows added to what is
  there: INSERT_INTO; a rerun adds them twice.
- **R3** One named Partition: `INSERT_OVERWRITE(t, partition={"dt": day})`, its column left
  out of SELECT.
- **R4** A table with a Key gets one row per Key, by GROUP_BY over it or SELECT_DISTINCT,
  or the write is refused. `unproven_key=True` only if the user says why.
- **R5** The logic cell has W2's shape, `PARTITIONED_BY = []` for none, and calls no
  run_query or run_execute.
- **R6** Asked for `rows(day)`: rows takes `day`, its read `equals(t.dt, day)`, under a
  constant `DAY = "2026-09-24"`; `preview()` is `statement(*rows(DAY))`, `write()`
  `statement(INSERT_OVERWRITE(t), *rows(DAY))`.
- **R7** Several days a run, or a Scheduled run's period (file 18):
  `rows(first_day, last_day)` bounds its read with `between(...)`;
  `write_days(first_day, last_day)` is `statement(INSERT_OVERWRITE(t), *rows(first_day,
  last_day))`; `write()` takes nothing and returns `write_days(...)` with its own days.
- **R8** Sent by hand: `run_execute(create(), execute)`, then
  `run_execute(hive_settings("dynamic_partitions"), execute)`, then
  `run_execute(write(), execute)`.
- **R9** Otherwise the next cell runs `show_hive([create(), write()])` and
  `run_query(preview(), query)`; `project.run_tables(execute=execute)` sends the writes.
- **R10** `project.new_table(...)` (file 14) makes the notebook; its `export_hive()` cell
  writes its .hql beside it.
- **R11** Its kind is a Decision (file 14): `"kind": "history"` if each write keeps the
  rows there (R2's INSERT_INTO, R3); `"rebuilt"` if it replaces the table; `"proposed"`
  accepts it.

## Worked patterns

### W1: one day's rows written into a Saved table, replacing the day

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, INSERT_OVERWRITE, SELECT, WHERE,
                              count_rows, equals, statement)
from references.mart__job_day_events import job_day_events
from references.ops__job_events import job_events

s = statement(
    INSERT_OVERWRITE(job_day_events),
    SELECT(job_events.job_id, AS(count_rows(), "events"), job_events.dt),
    FROM(job_events),
    WHERE(equals(job_events.dt, "2026-09-24")),
    GROUP_BY(job_events.job_id, job_events.dt),
)
```

### W2: mart.job_day_events's logic cell (Key job_id and dt)

```python
# logic
from sqlglot_composer import (AS, FROM, GROUP_BY, INSERT_OVERWRITE, SELECT, WHERE, Clause,
                              Statement, count_rows, create_table, equals, statement)
from references.mart__job_day_events import job_day_events
from references.ops__job_events import job_events

READS = equals(job_events.dt, "2026-09-24")
PARTITIONED_BY = ["dt"]


def create() -> Statement:
    return create_table(job_day_events, may_exist=True)


def rows() -> list[Clause]:
    return [
        SELECT(job_events.job_id, AS(count_rows(), "events"), job_events.dt),
        FROM(job_events),
        WHERE(READS),
        GROUP_BY(job_events.job_id, job_events.dt),
    ]


def preview() -> Statement:
    return statement(*rows())


def write() -> Statement:
    return statement(INSERT_OVERWRITE(job_day_events), *rows())
```
