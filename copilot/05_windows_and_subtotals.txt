## Terms

- **Statement**: one Hive query; a **Condition**, a test on rows; `t`, a table: `job_runs`.
- **Window**: which rows each row looks across, `window(...)`.
- **Derived table**: a named Statement, `derived(...)`, read like a table.

## Rules

- **R1** `window(PARTITION_BY=t.job_id, ORDER_BY=t.run_id)`: the rows of each job, in order;
  several columns as lists; `descending(t.minutes)` for largest first. `rows=(-6, 0)` looks
  across the 6 rows before and the row itself; `rows=(None, 0)` every row up to it.
- **R2** Pass it as `over=`: `rank(over=w)`, `ntile(4, over=w)`, `lag(t.minutes, over=w)`
  (the row before), `lead(...)` (after), `first_value`, `last_value`, `sum_of(t.minutes,
  over=w)`, `count_rows(over=w)`. rank, lag and lead need ORDER_BY; a total with ORDER_BY
  needs rows=. `row_number(PARTITION_BY=..., ORDER_BY=...)` numbers each group's rows.
- **R3** A window's value is tested only in a Statement reading its Derived table, never in
  its own WHERE or HAVING; it is never added up again. The latest row: row_number from the
  newest, keep `equals(d.n, 1)`; never max_of on each column, which mixes rows.
- **R4** Ties: add a second ORDER_BY column, as a list:
  `ORDER_BY=[descending(t.duration_mins), t.run_id]`.
- **R5** Subtotals go inside GROUP_BY: `rollup(t.dt)` adds a total of every day;
  `cube(a, b)` every combination; `grouping_sets(...)` the sets named. A total's row is
  NULL in each column it totals over.
- **R6** Only if the user asks for a label on a total's row:
  `AS(if_else(is_total(t.dt), "all days", t.dt), "dt")`.
- **R7** `UNION_ALL(s1, s2)` gives the rows of both, each Statement with the same columns in
  the same order, each bounded; `UNION` drops repeats; `INTERSECT`, `EXCEPT` as in SQL.

## Worked patterns

### W1: the latest run of each job over two days

```python
from sqlglot_composer import (AS, FROM, SELECT, WHERE, between, derived, descending, equals,
                              row_number, statement)
from references.ops__job_runs import job_runs

numbered = derived("numbered", statement(
    SELECT(job_runs.job_id, job_runs.run_id, job_runs.status,
           AS(row_number(PARTITION_BY=job_runs.job_id, ORDER_BY=descending(job_runs.run_id)),
              "newest_first")),
    FROM(job_runs),
    WHERE(between(job_runs.dt, "2026-09-23", "2026-09-24")),
))
s = statement(
    SELECT(numbered.job_id, numbered.run_id, numbered.status),
    FROM(numbered),
    WHERE(equals(numbered.newest_first, 1)),
)
```

### W2: a running total of each job's minutes, in run order

```python
from sqlglot_composer import AS, FROM, SELECT, WHERE, equals, statement, sum_of, window
from references.ops__job_runs import job_runs

each_job = window(PARTITION_BY=job_runs.job_id, ORDER_BY=job_runs.run_id, rows=(None, 0))
s = statement(
    SELECT(job_runs.job_id, job_runs.run_id,
           AS(sum_of(job_runs.duration_mins, over=each_job), "minutes_so_far")),
    FROM(job_runs),
    WHERE(equals(job_runs.dt, "2026-09-24")),
)
```

### W3: runs per job and day, totals per job (dt NULL) and of all

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, SELECT, WHERE, between, count_rows,
                              rollup, statement)
from references.ops__job_runs import job_runs

s = statement(
    SELECT(job_runs.job_id, job_runs.dt, AS(count_rows(), "runs")),
    FROM(job_runs),
    WHERE(between(job_runs.dt, "2026-09-23", "2026-09-24")),
    GROUP_BY(rollup(job_runs.job_id, job_runs.dt)),
)
```
