# Copilot files for sqlglot Composer 8.7: start here

**Find the words you would type in the Index, load the file it names into a new chat, then
follow the steps below in order.**

sqlglot Composer 8.7 writes Hive, the SQL of your warehouse, from Python: you build a Statement from
Clause functions, such as SELECT, FROM and WHERE, and the Toolbox writes its Hive and refuses
one that would give a wrong number or read too much. These files teach Microsoft Copilot to
write that Python, so you can ask it in plain words.

  as a .hql file, 14.
- **R6** For an Excel workbook, attach files 15, 11 and 12 (or paste each as a message of

## Terms

- **Copilot file**: one of the files in this folder; each teaches Copilot one objective.
- **Statement**: one query, built in Python with `statement(...)`, that becomes Hive.
- **Project**: your folder at work holding the Toolbox and your own code.
- **Table reference**: the file in your Project's references/ folder that describes one
  table: its columns and their types, its partitions and its Key.
- **Saved table**: a table in the warehouse that your own Statements write.
- **Workflow**: the steps to one end goal, such as converting Hive, each a cell of the
  Workflow's notebook in admin/workflows/.
- **Run value**: the value a function of yours works out each time a table is written.
- **Your chatbot**: the chatbot at your work that knows your databases; not Copilot.

## Steps

1. **Choose.** Find your words in the Index, and the Rules where two lines fit. Done when
   you have one file, or three for a workbook. Then step 2.
2. **Load.** Open a new chat in Copilot; paste the file as your first message and send it,
   or attach it if a paste is cut short. Then step 3.
3. **Ask.** Name each table to read: paste its Table reference, or say its import line and
   columns, such as: `from references.ops__job_runs import job_runs` gives ops.job_runs:
   run_id bigint, job_id bigint, status string, dt string; partitioned by dt; Key run_id.
   For file 19, paste your column definitions and say the metric; for a workbook, attach
   it. Then step 4.
4. **Run.** Run what Copilot gives in your notebook. If the Toolbox refuses it, start a new

   workbook's Hive: save each query as a .hql file and run the convert Workflow (file 13).

## Terms

## Rules

- **R1** The Project is any folder of the user's, such as my_project/, with
  `sqlglot_composer/` copied in whole. There, `from sqlglot_composer import project`, then
  `project.start()`, writes admin/, references/, building_blocks/, tables/ and warehouse.py.
- **R2** warehouse.py holds `connect(connection)`, which each notebook's setup cell calls

- **R8** A Windows path is typed with forward slashes, `"C:/work/my_project"`.

## Always: rules A1 to A10

- **A1** Import each name you use, by name: `from sqlglot_composer import FROM, SELECT,
  statement`, never `import *`. Write only Toolbox names this file or the user's code shows:
  there is no COUNT, SUM, AND, CASE or ALIAS function.
- **A2** One `statement(...)`, its Clause functions in SQL order: a write's INSERT_OVERWRITE
  or INSERT_INTO first, then SELECT or SELECT_DISTINCT, FROM, the joins, WHERE, GROUP_BY,
  HAVING, ORDER_BY, LIMIT.
- **A3** Name every calculation with AS: `AS(count_rows(), "runs")`; a plain column needs
  none. `+ - * /` work on Columns; comparisons are A4's.
- **A4** Write each Condition with a function, never Python's ==, <, >, and, or, not on a
  Column: equals, not_equals, more_than, less_than, at_least, at_most, between, is_in,
  is_not_in, is_null, is_not_null, all_of, any_of. WHERE(a, b) keeps rows where both hold.
- **A5** **Bound every read of a partitioned table** with a value for one of its partition
  columns, such as `equals(t.dt, "2026-09-24")`, `between(...)`, `is_in(...)` or

  SEMI_JOIN and ANTI_JOIN; for FULL_JOIN, in a Derived table it reads. Matching it to another
  table's column bounds nothing. A table with no partitions needs no bound.
- **A6** Give every ORDER_BY a LIMIT.
- **A7** Run a read with `run_query(s, query)` and a write with `run_execute(s, execute)`,
  after `from warehouse import query, execute`. Never call query or execute yourself.
- **A8** Add an opt-out, such as `reads_all_partitions=True`, only when the user asks for
  what it allows, and say why in a comment.
- **A9** Reach a column as `table.column`, from the user's Table reference:
  `from references.ops__job_runs import job_runs`, then `job_runs.dt`.
- **A10** If this file doesn't cover the request, say so and name the file to load in a new
  chat: 01 the Project, 02 Table references, 03 a Statement, 04 joins, 05 windows and

## Rules: formulas

- **F1** `+ - * /` as they are; `^` POWER; `&` CONCAT(a, b); TRUE, FALSE kept.
- **F2** AND(a, b, c): `a AND b AND c`; OR(a, b): `(a OR b)`, bracketed, as AND joins before
  OR; NOT(x): `NOT x`. Hive has no AND() or OR(): IF(AND(a, b), 1, 0) is IF(a AND b, 1, 0).
- **F3** IF as it is. IFS(c1, v1, c2, v2): `CASE WHEN c1 THEN v1 WHEN c2 THEN v2 END`.

- **F4** IFERROR(a / b, 0): COALESCE(a / b, 0), as a divide by 0 is NULL; IFNA(x, v) and
  XLOOKUP's fourth argument, v: COALESCE(x, v). ISBLANK(x): x IS NULL. ROUND, ABS, POWER,
  SQRT as they are; MOD(a, b): PMOD(a, b); INT: FLOOR; MIN(a, b) and MAX(a, b) of one row's
  cells: LEAST and GREATEST.
- **F5** LEFT(x, n): SUBSTR(x, 1, n); RIGHT(x, n): SUBSTR(x, -n); MID(x, s, n): SUBSTR(x, s,

  ISNUMBER(FIND(..)): INSTR(..) > 0; SUBSTITUTE: REPLACE; PROPER: INITCAP; CONCATENATE:
  CONCAT; TEXTJOIN(",", TRUE, a, b): CONCAT_WS(',', a, b); VALUE(x): CAST(x AS DOUBLE);
  UPPER, LOWER, TRIM as they are.
- **F6** YEAR, MONTH, DAY as they are; DATE(2026,9,1): '2026-09-01'; TODAY(): CURRENT_DATE;
  d + n, d - n: DATE_ADD(d, n), DATE_SUB(d, n); a date minus a date, b - a: DATEDIFF(b, a);
  DATEDIF(a, b, "d"): DATEDIFF(b, a), "m": FLOOR(MONTHS_BETWEEN(b, a)), "y":
  FLOOR(MONTHS_BETWEEN(b, a) / 12); EOMONTH(d, 0): LAST_DAY(d); EDATE(d, n): ADD_MONTHS(d,
  n), marked: a month's end stays one; WEEKDAY(d): DAYOFWEEK(d); TEXT(d, "yyyy-mm"):
  DATE_FORMAT(d, 'yyyy-MM').
- **F7** The first of d's month, DATE(YEAR(d), MONTH(d), 1) or EOMONTH(d, -1)+1:
  `CAST(TRUNC(d, 'MM') AS STRING)`. The Monday of d's week, d-WEEKDAY(d,2)+1:
  `CAST(NEXT_DAY(DATE_ADD(d, 7 * -1), 'MO') AS STRING)`.

  its value, written into the Hive, and said in the map: change it in Parameters and the
  table won't follow. A summary's groups, written in (file 15): said in the map too.
- **F9** SUMIFS(t[v], t[a], [@a], t[s], "x") over its own Table: `SUM(CASE WHEN s = 'x' THEN
  v END) OVER (PARTITION BY a)`. Over another Table: LEFT JOIN `(SELECT a, SUM(v) AS total
  FROM t WHERE s = 'x' GROUP BY a)`. Either way COALESCE(.., 0), as Excel gives 0 where
  nothing matches. COUNTIFS: COUNT(*), MAXIFS: MAX, MINIFS: MIN, each with COALESCE too;
  AVERAGEIFS: AVG, left NULL. SUMIF and AVERAGEIF(t[a], [@a], t[v]), COUNTIF(t[a], [@a]):
  the -IFS form, one match.
- **F10** RANK.EQ(x, t[x]) or RANK: `RANK() OVER (ORDER BY x DESC)`; with 1 as a third
  argument, ASC.

## Rules: conditions in an -IF(S) form

- **I1** "x": `s = 'x'`; ">10", ">=", "<", "<=": that comparison; "<>x": `(s <> 'x' OR s IS
  NULL)`, as Excel counts a blank there; "<>" alone: `s IS NOT NULL`; ">="&[@d]: against
  this row's d.
- **I2** Every condition of one -IFS form holds at once: join them with AND, two on one
  column too (">10" and "<=30": `v > 10 AND v <= 30`). Two -IFS forms added that differ in
  one value only: one form, `s IN ('x', 'y')`.
- **I3** SUMPRODUCT over conditions: `*` is AND; `+` is OR where both can't hold at once, or
  written `((..)+(..)>0)`. SUMPRODUCT((t[s]="x")*(t[v]>5)*t[v]): `SUM(CASE WHEN s = 'x' AND
  v > 5 THEN v ELSE 0 END)`; with no column to add, as `(..)*1`: `COUNT(CASE WHEN .. THEN 1
  END)`. Over its own Table, each row shows the same total: `SUM(...) OVER ()`.
- **I4** A wildcard, "*ail*" or "f*": `LOWER(s) LIKE '%ail%'`, `'f%'`, as Excel ignores case.
- **I5** `t[d], "<="&[@d]` over its own Table is a running total, ties included: `SUM(v)
  OVER (PARTITION BY a ORDER BY d RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)`;
  COUNTIFS the same with COUNT(*). COUNTIFS(t[a], [@a], t[v], ">"&[@v])+1: `RANK() OVER
  (PARTITION BY a ORDER BY v DESC)`; with "<", ASC.
- **I6** A window's ORDER BY and PARTITION BY read the source's columns, as `ORDER BY dt`,
  never a name the same SELECT makes with AS.

## Rules: a value typed over a formula

- **V2** No Keys row for it: match every typed column of the row, and say so.

## Rules: marks, converted and named

- **M2** VLOOKUP or MATCH with TRUE or 1: the exact match; mark "approximate".

  reads as a date stays as it is**: shown, compared in -IFS or ordered on, `dt` is `dt`.
- **M4** A lookup whose key repeats in the looked-up Table's sample: Excel takes the first
  match, a LEFT JOIN every one. Write the LEFT JOIN, mark "repeated key".
- **M5** A defined name for a cell outside a Table: its value; say to move it to Parameters.

## Terms

- **M**: Power Query's language. A query is a `let` of named steps, each reading the one
  before; `in` names the step it gives. Read the steps in order.
- **Total Row**: the row Excel adds inside a Table's range, under its last row, each total a
  SUBTOTAL(...) over a column: the workbook shows it as the Table's `Total Row`. It is the
  Total Row, never a row of data.
- A query step no rule here lists is refused: NULL for each column it makes, or the query
  left out, named with why.

## Rules: reading a table and its rows

- **Q1** `Excel.CurrentWorkbook(){[Name="t"]}[Content]` reads Table t, as `<database>.t`.
  Another query's name, as in `Table.Sort(q, ...)`, reads query q: a CTE, `WITH q AS
  (...)`, after each CTE q reads: a query, then the Table it loads, then a formula column
  reading that Table. `#date(2026, 9, 1)`: '2026-09-01'.
- **Q2** Table.SelectRows: WHERE; after a Table.Group, HAVING, repeating the aggregate. M's

- **Q3** Text.Contains([c], "x"), Text.StartsWith, Text.EndsWith: `c LIKE '%x%'`, `'x%'`,

- **Q4** List.Contains({1, 3}, [c]): `c IN (1, 3)`. List.Contains(u[k], [k]), a row whose k
  is in another table: `LEFT SEMI JOIN u ON u.k = t.k`; with `not`, G2's LeftAnti.
- **Q5** Table.SelectColumns, RemoveColumns, RenameColumns, ReorderColumns: the SELECT list,
  in the last step's order; Table.DuplicateColumn(t, "c", "d"): `c, c AS d`.
  TransformColumnTypes, Table.Buffer, Table.PromoteHeaders: nothing. Excel's step names,
  such as "Changed Type", are only names: read the function each step calls.
- **Q6** Table.AddColumn: an expression AS its name, `if c then a else b` as IF(c, a, b).

  0, Replacer.ReplaceValue, {"c"}): COALESCE(c, 0) AS c; with "x", "y" and
  Replacer.ReplaceText: REPLACE(c, 'x', 'y') AS c; with Replacer.ReplaceValue and a value:

- **Q7** As their twins in file 11: Text.Upper, Text.Lower, Text.Trim, Text.Length;

## Rules: grouping, joining, stacking

- **G1** Table.Group: GROUP BY, Table.RowCount(_) as COUNT(*), List.Sum, List.Max, List.Min,
  List.Average as SUM, MAX, MIN, AVG, List.StandardDeviation as STDDEV_SAMP.
  List.Count(List.Distinct([c])): COUNT(DISTINCT c), which leaves out NULL where M counts it:
  name it where c has a blank in the sample.
- **G2** NestedJoin then ExpandTableColumn, by JoinKind: LeftOuter: LEFT JOIN; Inner: JOIN;
  RightOuter: LEFT JOIN, the tables swapped; FullOuter: FULL OUTER JOIN; LeftAnti: `LEFT
  JOIN u ON t.k = u.k WHERE u.k IS NULL`, t's columns only; RightAnti: the same, swapped.
  ExpandTableColumn's fourth argument, new names: AS.
- **G3** A NestedJoin on every column, its new column removed, in Table.Distinct: Inner is
  `INTERSECT`, LeftAnti is `EXCEPT`. Table.AddColumn(t, "u", each u), expanded: `CROSS JOIN
  u`.
- **G4** Table.Combine: UNION ALL; inside Table.Distinct, UNION. Table.Distinct alone:
  SELECT DISTINCT.
- **G5** Table.Unpivot(t, {"a", "b"}, "measure", "amount") or UnpivotOtherColumns: one SELECT
  per column, stacked with UNION ALL, `'a' AS measure, a AS amount`, each `WHERE a IS NOT
  NULL`, as M drops a null there.

## Rules: a whole column, and the Total Row

- **T1** SUM(t[v]), AVERAGE, COUNT, COUNTA, MIN, MAX in a formula column: `SUM(v) OVER ()`
  and so on, COUNTA as COUNT(v); STDEV.S: STDDEV_SAMP; VAR.S: VAR_SAMP; SUMPRODUCT(t[a],

- **T3** If the user says no one needs a Total Row kept: no block; name it as left out.

- **S2** Table.AddIndexColumn(t, "n", 1, 1) after a Table.Sort: `ROW_NUMBER() OVER (ORDER BY
