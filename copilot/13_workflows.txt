## Terms

- **Workflow**: ordered steps to one end goal; each step is a cell of its notebook,
  admin/workflows/<name>/<name>.ipynb. Its **names cell** holds its inputs in capitals.
- **Decision**: one thing about one table only the user decides, such as its location, Key
  or a column type, answered in the **decisions cell**, DECISIONS.
- **Saved table**: a table the user's own code writes; its **Table reference** is the file
  of its columns, partitions, Key and location.
- **DEV**: the Dev Database, in admin/databases.py; **query**, **execute**: the user's
  warehouse calls.

## Rules

- **R1** **The names cell comes first, filled in, every time**: the cells after it read NAME
  and the other inputs. Then only the cells asked, each as the steps list it; a step's cell
  runs once the steps before it are done.
- **R2** Asked for every step's cell, or through the compare: the names cell, step 1, the
  decisions cell, then steps 3 to 7 as listed, in order.
- **R3** FILES: .hql files by name beside the notebook, `["daily.hql"]`, else by full path;
  `HIVE = None`. Hive given as text: `FILES = []`, `HIVE = """..."""`. A query that only
  SELECTs makes a Saved table too.
- **R4** DATABASE: the database of a table the Hive names without one; else
  `DATABASE = "default"`.
- **R5** Each dev copy is named `<table>_<its database>` in DEV, as mart_dev.team_fails_mart;
  a name the user says convert gives is that one: `RENAME = {}`. Only for another name the
  user asks: `{"mart.team_fails": "team_fails"}`, by the full name, no database on the right.
- **R6** STAGING: a staging table is one a statement makes and a later one reads, by its
  name as the Hive writes it. Folded, its query goes inside each reader:
  `{"ops_reports.failed": "fold"}`; kept, a Saved table: "keep". Not named, `STAGING = {}`.
- **R7** `EACH_SCRIPT_ITS_OWN_BATCH = True` makes each file a batch of its own.
- **R8** DECISIONS holds each answer by the table's name as `project.check()` writes it:
  `{"mart_dev.weekly": {"key": ["job_id"], "types": {"dt": "string"}, "location":
  "/data/team/mart_dev.db/weekly"}}`. Write each answer the user gives; name each other: a
  Decision is the user's. None open: `DECISIONS = {}`.
- **R9** A Script tag, `<PARM="NAME"/>`, is a Decision under "tags", answered with the value
  the user gives: a bare one with its own quotes, `"'2026-10-31'"`, one inside quotes with
  none, `"failed"`. The old scheduler filling it is no reason to leave it open. No value
  given: ask. Worked out each run: a Run value (file 17).
- **R10** `"all_tables": {"key": "proposed"}` accepts each proposed Key; once the batch has
  finished: `project.write_decisions(DECISIONS, tables=project.batch_tables(NAME))`.
- **R11** `PARTITIONS = []` unless the user names a Partition for step 7 too. Once in
  finished/: `project.compare_batch(NAME, query=query, partitions=[{"dt": ...}])`.
- **R12** "Run up to your Decisions", then "Run the rest", `project.run_workflow(...)`, run
  each to the first step only the user can do; `dry_run=True` sends nothing. Promoting is
  file 16's.

## Names for this objective, with their arguments

- project.check()
- project.run_workflow(workflow, *, query=None, execute=None, dry_run=False, change=None)
- project.convert(name, hive=None, *, file=None, files=None, query=None, database='default', rename=None, overwrite=False, staging=None)
- project.compare_batch(name, *, query=None, tables=None, partitions=None)
- project.write_decisions(answers, tables=None, *, query=None)
- project.batch_tables(name, seeded=False)

## The steps of convert

1. Convert the scripts: each table they write a Saved table in dev (it is a call to the
   warehouse, yours to run).

       project.convert(NAME, HIVE, files=FILES, query=query, database=DATABASE,
                       rename=RENAME, staging=STAGING)

2. Answer each table's open Decisions in the decisions cell (it is a decision, yours to make).
3. Write each answer into its table's Table reference (it changes only files, so
   project.do_next() runs it for you).

       project.write_decisions(DECISIONS, tables=project.batch_tables(NAME),
                               query=query)

4. Create each table in dev (it is a call to the warehouse, yours to run).

       for table in project.batch_tables(NAME):
           run_execute(project.load(table).create(), execute)

5. Seed each table that reads itself, once, from its original (it is a call to the warehouse,
   yours to run).

       to_seed = project.batch_tables(NAME, seeded=True)
       if not to_seed:
           print("Seeded nothing: no table of the batch reads itself.")
       else:
           run_execute(hive_settings("dynamic_partitions"), execute)
           for table in to_seed:
               run_execute(project.load(table).seed(), execute)

6. Write each table in dev (it is a call to the warehouse, yours to run).

       project.run_tables(tables=project.batch_tables(NAME), execute=execute)

7. Compare each table with its original (it is a call to the warehouse, yours to run).

       project.compare_batch(NAME, query=query, partitions=PARTITIONS)

```python
                rename=RENAME, staging=STAGING)
```

```python
project.write_decisions(DECISIONS, tables=project.batch_tables(NAME))
```
