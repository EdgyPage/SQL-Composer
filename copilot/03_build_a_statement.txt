## Terms

- **Statement**: one Hive query, `statement(...)` of Clause functions such as `SELECT(...)`;
  a **Condition**, a test on rows: `equals(...)`.
- `t`: a table, as its Table reference describes it: `job_runs`.
- **Derived table**: a named Statement, `derived(...)`, read like a table.

## Rules

- **R1** Each clause only where needed. Every column of a table: `SELECT(*all_columns(t))`.
- **R2** Days are written as the table holds them, "2026-09-24" or "20260924";
  `last_n_days(t.dt, 7)` is the 7 days before today.
- **R3** Every day of `t`, asked for: `FROM(t, reads_all_partitions=True)`, with a comment.
- **R4** `count_rows()` counts rows; `count_rows(where=equals(t.status, "FAILED"))` only
  those; `count_distinct(t.job_id)` different values; `sum_of`, `average_of`, `min_of`,
  `max_of` the rest, each named with AS.
- **R5** Every SELECT column that isn't added up goes in GROUP_BY; a calculation by its AS
  name, as text: `GROUP_BY(t.job_id, "hours")`. HAVING tests a total:
  `HAVING(more_than(average_of(t.minutes), 15))`.
- **R6** A top N: `ORDER_BY(descending(t.minutes))`, then `LIMIT(10)`. A whole result is
  sorted in pandas: `run_query(s, query).sort_values("minutes")`.
- **R7** A share or percent divides two totals in one AS:
  `AS(count_rows(where=equals(t.status, "FAILED")) * 100 / count_rows(), "fail_pct")`;
  Hive's `/` gives a decimal.
- **R8** NULL: `is_null(t.owner)`, never `equals(t.owner, None)`; NULL made a value:
  `fill_null(t.status, "running")`. Two labels: `if_else(condition, then, otherwise)`.
- **R9** `d = derived("d", statement(...))`, then `FROM(d)` and `d.runs`; no LIMIT inside
  it. One used in several notebooks is a function in building_blocks/<name>.py.

## Always: rules A1 to A10

- **A1** Import each name you use, by name: `from sqlglot_composer import FROM, SELECT,
  statement`, never `import *`. Write only Toolbox names this file or the user's code shows:
  there is no COUNT, SUM, AND, CASE or ALIAS function.
- **A2** One `statement(...)`, its Clause functions in SQL order: a write's INSERT_OVERWRITE
  or INSERT_INTO first, then SELECT or SELECT_DISTINCT, FROM, the joins, WHERE, GROUP_BY,
  HAVING, ORDER_BY, LIMIT.
- **A3** Name every calculation with AS: `AS(count_rows(), "runs")`; a plain column needs
  none. `+ - * /` work on Columns; comparisons are A4's.
- **A4** Write each Condition with a function, never Python's ==, <, >, and, or, not on a
  Column: equals, not_equals, more_than, less_than, at_least, at_most, between, is_in,
  is_not_in, is_null, is_not_null, all_of, any_of. WHERE(a, b) keeps rows where both hold.
- **A5** **Bound every read of a partitioned table** with a value for one of its partition
  columns, such as `equals(t.dt, "2026-09-24")`, `between(...)`, `is_in(...)` or
  `last_n_days(t.dt, 7)`: in WHERE for FROM, JOIN and CROSS_JOIN; inside ON= for LEFT_JOIN,
  SEMI_JOIN and ANTI_JOIN; for FULL_JOIN, in a Derived table it reads. Matching it to another
  table's column bounds nothing. A table with no partitions needs no bound.
- **A6** Give every ORDER_BY a LIMIT.
- **A7** Run a read with `run_query(s, query)` and a write with `run_execute(s, execute)`,
  after `from warehouse import query, execute`. Never call query or execute yourself.
- **A8** Add an opt-out, such as `reads_all_partitions=True`, only when the user asks for
  what it allows, and say why in a comment.
- **A9** Reach a column as `table.column`, from the user's Table reference:
  `from references.ops__job_runs import job_runs`, then `job_runs.dt`.
- **A10** If this file doesn't cover the request, say so and name the file to load in a new
  chat: 01 the Project, 02 Table references, 03 a Statement, 04 joins, 05 windows and

## Worked patterns

### W1: each job's runs and minutes over two days, more than one run, run

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, HAVING, SELECT, WHERE, between,
                              count_rows, more_than, run_query, statement, sum_of)
from references.ops__job_runs import job_runs
from warehouse import query

s = statement(
    SELECT(job_runs.job_id, AS(count_rows(), "runs"),
           AS(sum_of(job_runs.duration_mins), "minutes")),
    FROM(job_runs),
    WHERE(between(job_runs.dt, "2026-09-23", "2026-09-24")),
    GROUP_BY(job_runs.job_id),
    HAVING(more_than(count_rows(), 1)),
)
rows = run_query(s, query)
```

### W2: in two steps, a Derived table first

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, SELECT, WHERE, count_rows, derived,
                              equals, is_in, statement)
from references.ops__job_events import job_events

ends = derived("ends", statement(
    SELECT(job_events.job_id, job_events.event_type),
    FROM(job_events),
    WHERE(equals(job_events.dt, "2026-09-24"), is_in(job_events.event_type, ["finish", "fail"])),
))
s = statement(
    SELECT(ends.event_type, AS(count_rows(), "events")),
    FROM(ends),
    GROUP_BY(ends.event_type),
)
```
