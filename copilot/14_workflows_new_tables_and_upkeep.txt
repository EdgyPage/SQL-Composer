Objective: take the user through a job on their own Project with sqlglot Composer 8.9, each step a

Load this file when the user asks for a new Saved table, Table references, an upgrade, or a

## Patterns: when the user says X, do Y

| ID | The user says | Do | Copy |
|---|---|---|---|
| P1 | "Table references for ops.a and ops.b" | references: `TABLES`, step 1 | W1 |
| P2 | "a new Saved table, logic I'll write" | new_table: `QUERIES = {}`, step 1 | W2 |
| P3 | "a new table from my query in x.hql" | `QUERIES = {"x": "x.hql"}` | R3 |
| P4 | "I doubt the proposed Key" | `check_key(...)` on one day first | R6 |

| P8 | "run it all", "run to my Decisions" | `project.run_workflow(...)` | R10 |

## Terms

- **Workflow**: ordered steps to one end goal; each step is a cell of its notebook,
  admin/workflows/<name>/<name>.ipynb. Its **names cell** holds its inputs in capitals.
- **Decision**: one thing about one table only the user decides, such as its location, Key
  or a column type, answered in the **decisions cell**, DECISIONS.
- **Saved table**: a table the user's own code writes, from its **Table notebook**'s logic;
  its **Table reference** is the file of its columns, partitions, Key and location.
- **DEV**: the Dev Database, in admin/databases.py; its "location_root" places each table.
- **Admin statement**: a Statement that changes a Saved table's definition or deletes its
  data; an **UPGRADE mark**, a comment an upgrade leaves for the user.

## Rules

- **R1** The names cell comes first, filled in: TABLES by full name, as
  `["mart_dev.job_day_counts"]`. Then only the cells asked, each as its steps list it.
- **R2** Asked for every step's cell: each one as listed, in order.
- **R3** A new table from a query: QUERIES gives its .hql file by the table's name without
  its database, and the table is made from it. No query: `QUERIES = {}`.
- **R4** **A new table's Table reference is written from its logic, never by hand.**
- **R5** DECISIONS holds each answer by table: `{"mart_dev.weekly": {"key": ["job_id"]}}`.
  Write each answer the user gives; name each other: a Decision is the user's.
- **R6** references' step 1 proposes each Key, checked, marked # proposed;
  `"all_tables": {"key": "proposed"}` accepts every one. A doubted Key: give
  `check_key(t, query=query, where=equals(t.dt, day))` on one day before they answer.
- **R7** A `# TODO` line, such as the first line or `does_not_add_up=`, is no Decision.
- **R8** At an upgrade, naming DEV and PROD renames nothing: each Saved table keeps its name
  and folder.
- **R9** A change to a Saved table: its Admin statement, its Hive shown, then sent.
- **R10** "Run up to your Decisions" and "Run the rest" (new_table, references), one call run
  before and after the answers, each to the first step the user must do;
  `dry_run=True` sends nothing.

## The steps of new_table: a Saved table of your own

1. Make each Table folder, converting each table's query QUERIES gives (it changes only files,
   so project.do_next() runs it for you).

       project.new_table(TABLES, queries=QUERIES, query=query)

2. Write each table's logic in its Table notebook, and save it (it is a decision, yours to
   make).

       for table in TABLES:
           project.load(table).preview()  # says what stops it, if anything does

3. Write each Table reference from its logic (it changes only files, so project.do_next() runs
   it for you).

       project.reference_from_logic(TABLES, query=query)

4. Answer each table's open Decisions in the decisions cell (it is a decision, yours to make).
5. Write each answer into its table's Table reference (it changes only files, so
   project.do_next() runs it for you).

       project.write_decisions(DECISIONS, tables=TABLES)

6. Check each table's rows with preview(), which writes nothing (it is a call to the warehouse,
   yours to run).

       for table in TABLES:
           print(run_query(project.load(table).preview(), query))

7. Create and write each in dev (it is a call to the warehouse, yours to run).

       for table in TABLES:
           run_execute(project.load(table).create(), execute)
       print(project.seed_tables(TABLES, query=query, execute=execute))
       project.run_tables(tables=TABLES, execute=execute)

8. Compare each table made from a query with its query (it is a call to the warehouse, yours to
   run).

       for name in QUERIES:
           print(project.compare_batch(name, query=query))


## The steps of references: Table references for tables you read

1. Write the Table references from DESCRIBE (it is a call to the warehouse, yours to run).

       project.add_references(TABLES, query=query)

2. Answer each table's open Decisions in the decisions cell (it is a decision, yours to make).
3. Write each answer into its table's Table reference (it changes only files, so
   project.do_next() runs it for you).

       project.write_decisions(DECISIONS, tables=TABLES)

4. Refresh the Reference sheet and the Database modules (it changes only files, so
   project.do_next() runs it for you).

       project.refresh_reference_sheet(TABLES)


## The steps of upgrade: a new Toolbox copied in

1. Upgrade the Project's files (it changes only files, or only prints: run its cell).

       project.upgrade()

2. Make each change an UPGRADE mark asks for, and delete the mark (it is a decision, yours to
   make).

## The steps of change_a_saved_table: an Admin statement on a Saved table

1. Write the Admin statement for the change (it is a decision, yours to make).

       from sqlglot_composer import between, equals  # where= takes a Condition
       table = project.table_reference(TABLE)
       # such as where=equals(table.dt, "2026-09-24"), or a range of days,
       # where=between(table.dt, "2026-09-01", "2026-09-30"), dt its partition column
       change = admin.drop_partitions(table, where=...)  # or another: help(admin)

2. Print its Hive, and run the check its Check first line names (it is a call to the warehouse,
   yours to run).

       show_hive(change)
       print(query("SHOW PARTITIONS " + TABLE))

3. Send it, then any check after it, such as admin.check_the_copy (it is a call to the
   warehouse, yours to run).

       run_execute(change, execute)
       project.record_lineage_state()

4. **Name the rest**: each Decision left open, and each later step, in words. Then step 5.
5. **Check.** Tick each Self-check line; fix any that fails, then reply as Output says.
