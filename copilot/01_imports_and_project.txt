# Copilot file 01: imports and the Project (sqlglot Composer 8.9)

**Find the request in Patterns, copy the worked pattern it names, change only the tables,
columns and values, then tick the Self-check. Add nothing the user didn't ask for.**

Objective: set up a Project, import what Toolbox code needs, and run a Statement.
Load this file when the user starts a Project, asks what to import, or asks how to run
something and see its rows.

## Patterns: when the user says X, do Y

| ID | The user says | Do | Copy |

| P1 | "start a Project" | `project.start()` in the Project's folder | R1 |
| P2 | "read ... from ops.jobs" | `from references.ops__jobs import jobs` | W1 |

| P12 | a notebook in a subfolder | the Project's folder on `sys.path` first | R7 |

## Terms

- **Toolbox**: sqlglot Composer 8.9, which writes Hive from Python.
- **Project**: a folder holding the Toolbox's folder, `sqlglot_composer/`, and the user's
  notebooks.
- **Statement**: one Hive query, built with `statement(...)`.
- **Table reference**: a file in references/ describing one table: its columns, types,
  partitions and Key, the columns that tell one row from another.
- **Saved table**: a table the user's own notebook writes; a **Workflow**, a job's steps,
  run from its notebook in admin/workflows/.

## Rules

- **R1** The Project is any folder of the user's, such as my_project/, with
  `sqlglot_composer/` copied in whole. There, `from sqlglot_composer import project`, then
  `project.start()`, writes admin/, references/, building_blocks/, tables/ and warehouse.py.
- **R2** warehouse.py holds `connect(connection)`, which each notebook's setup cell calls
  first; `query(hive)`, giving a pandas DataFrame; and `execute(hive)`, which changes
  something. Imports: the Toolbox's, then the Table references, then warehouse's.
- **R3** A table to read: the references Workflow runs
  `project.add_references(["ops.job_runs"], query=query)`, writing
  references/ops__job_runs.py, its Key proposed for the user to accept.
- **R4** A Saved table: the new_table Workflow runs `project.new_table("mart.job_day_runs")`,
  writing its notebook and Table reference (file 06).
- **R5** `project.check()` names each Workflow notebook's next step; `project.do_next()` runs
  those it can. A Table reference's `# TODO` line blocks nothing.
- **R6** `send=` went in 7.0: `run_query(s, query)` reads, `run_execute(s, execute)` writes;
  never `query(s)` or `query(to_hive(s))`.
- **R7** In a subfolder, such as tables/mart__job_day_runs/: `import pathlib`, `import sys`,
  then `sys.path.insert(0, str(pathlib.Path.cwd().parents[1]))`.
- **R8** A Windows path is typed with forward slashes, `"C:/work/my_project"`.

## Always: rules A1 to A11

- **A1** Import each name you use, by name: `from sqlglot_composer import FROM, SELECT,
  statement`, never `import *`. Write only Toolbox names this file or the user's code shows:
  there is no COUNT, SUM, AND, CASE or ALIAS function.
- **A2** One `statement(...)`, its Clause functions in SQL order: a write's INSERT_OVERWRITE
  or INSERT_INTO first, then SELECT or SELECT_DISTINCT, FROM, the joins, WHERE, GROUP_BY,
  HAVING, ORDER_BY, LIMIT.
- **A3** Name every calculation with AS: `AS(count_rows(), "runs")`; a plain column needs
  none. `+ - * /` work on Columns; comparisons are A4's.
- **A4** Write each Condition with a function, never Python's ==, <, >, and, or, not on a
  Column: equals, not_equals, more_than, less_than, at_least, at_most, between, is_in,
  is_not_in, is_null, is_not_null, all_of, any_of. WHERE(a, b) keeps rows where both hold.
- **A5** **Bound every read of a partitioned table** with a value for one of its partition
  columns, such as `equals(t.dt, "2026-09-24")`, `between(...)`, `is_in(...)` or
  `last_n_days(t.dt, 7)`: in WHERE for FROM, JOIN and CROSS_JOIN; inside ON= for LEFT_JOIN,
  SEMI_JOIN and ANTI_JOIN; for FULL_JOIN, in a Derived table it reads. Matching it to another
  table's column bounds nothing. A table with no partitions needs no bound.
- **A6** Give every ORDER_BY a LIMIT.
- **A7** Run a read with `run_query(s, query)` and a write with `run_execute(s, execute)`,
  after `from warehouse import query, execute`. Never call query or execute yourself.
- **A8** Add an opt-out, such as `reads_all_partitions=True`, only when the user asks for
  what it allows, and say why in a comment.
- **A9** Reach a column as `table.column`, from the user's Table reference:
  `from references.ops__job_runs import job_runs`, then `job_runs.dt`.
- **A10** If this file doesn't cover the request, say so and name the file to load in a new
  chat: 01 the Project, 02 Table references, 03 a Statement, 04 joins, 05 windows and
  subtotals, 06 saving a table, 07 converting Hive, 08 checks, 09 a refusal, 10 labels and
  Hive by hand, 13 convert, 14 new tables and upkeep, 16 promote, 17 Run values and seeds, 18
  a Scheduled run, 19 a Metric request; an Excel workbook, 15 with 11 and 12.
- **A11** Read each Derived table once; SELECT in it only what is read after; filter and
  group before joining; fix rows a join repeats by its whole Key or a total first, not
  SELECT_DISTINCT.

## Worked patterns

### W1: one day's rows, the Hive shown, then run

```python
from sqlglot_composer import FROM, SELECT, WHERE, equals, run_query, statement, to_hive
from references.ops__job_runs import job_runs
from warehouse import query

s = statement(
    SELECT(job_runs.run_id, job_runs.job_id, job_runs.status),
    FROM(job_runs),
    WHERE(equals(job_runs.dt, "2026-09-24"), equals(job_runs.status, "FAILED")),
)
print(to_hive(s))
rows = run_query(s, query)
```

### W2: through `from references import ops`

```python
from sqlglot_composer import FROM, SELECT, WHERE, equals, statement
from references import ops

s = statement(
    SELECT(ops.job_runs.run_id, ops.job_runs.status),
    FROM(ops.job_runs),
    WHERE(equals(ops.job_runs.dt, "2026-09-24")),
)
```

### W3: a count for each value, run

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, SELECT, WHERE, count_rows, equals,
                              run_query, statement)
from references.ops__job_runs import job_runs
from warehouse import query

s = statement(
    SELECT(job_runs.status, AS(count_rows(), "runs")),
    FROM(job_runs),
    WHERE(equals(job_runs.dt, "2026-09-24")),
    GROUP_BY(job_runs.status),
)
rows = run_query(s, query)
```
