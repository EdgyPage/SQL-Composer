## Terms

- **Workflow**: ordered steps to one end goal; each step is a cell of its notebook,
  admin/workflows/<name>/<name>.ipynb. Its **names cell** holds its inputs in capitals.
- **Decision**: one thing about one table only the user decides, such as its location, Key
  or a column type, answered in the **decisions cell**, DECISIONS.
- **Saved table**: a table the user's own code writes; its **Table reference** is the file
  of its columns, partitions, Key and location.
- **DEV**, **PROD**: the Dev and Prod Databases, dicts in admin/databases.py, each a
  "database" and a "location_root", which places each new table's location.
- **prod copy**: the Saved table promote makes in PROD from a dev table, named for the dev
  table with PROD for its database.
- **query**, **execute**: the user's warehouse calls, imported with the Toolbox's names.

## Rules

- **R1** **A table is promoted once its compare has run** in the convert Workflow, or once
  the new_table Workflow (file 14) wrote it. A compare that failed, or wasn't compared, stops
  nothing: promote promotes it, its report naming it first, "Warning: promoting ...". Promoting
  is the user's call: say to read that table's conversion/compare.md first.
- **R2** The names cell comes first, filled in: TABLES, the dev tables by full name, such as
  `["mart_dev.daily_job_runs"]`. Left `[]`, the run cells promote every finished table not
  promoted yet, or changed since; `project.promote([])` itself is refused.
- **R3** Then only the cells asked, each as the steps list it; every step's cell when asked
  for every step, in order. A step's cell runs once the steps before it are done.
- **R4** A prod copy's location is the one an earlier promote gave it; else
  `<root>/<database>.db/<table>` under PROD's "location_root"; else a Decision left open,
  which `project.check()` names. The dev location is never carried over.
- **R5** DECISIONS holds each answer by the prod copy's name:
  `{"team_prod.daily_fails": {"location": "/data/team/prod/daily_fails"}}`. Write each
  answer the user gives; none open: `DECISIONS = {}`. A Decision is the user's.
- **R6** Another name for the prod copy: `project.promote(TABLES,
  rename={"mart_dev.daily_fails": "fails"})`.
- **R7** A prod copy that reads itself is seeded once, at step 5, every Partition unless its
  own "seed" answer limits it: `{"seed": {"dt": {"from": "2026-09-01"}}}`; a dev seed answer
  isn't carried over. "all_tables" answers every prod copy at once (file 17).
- **R8** A prod copy keeps its dev table's TAGS, a Run value or a Hivevar among them; each
  Building block it imports is copied into building_blocks/prod/.
- **R9** "Run up to your Decisions", then "Run the rest", run each to the first step only the
  user can do; `dry_run=True` sends nothing. With none open, the first runs to the end.

## Names for this objective, with their arguments

## The steps of promote

1. Promote each table: a prod copy of its folder and Table reference (it changes only files, so
   project.do_next() runs it for you).

       project.promote(TABLES)

2. Answer each prod table's open Decisions in the decisions cell (it is a decision, yours to
   make).
3. Write each answer into its prod table's Table reference (it changes only files, so
   project.do_next() runs it for you).

       project.write_decisions(DECISIONS, tables=project.promoted_tables(TABLES))

4. Create each table in prod (it is a call to the warehouse, yours to run).

       for table in project.promoted_tables(TABLES):
           run_execute(project.load(table).create(), execute)

5. Write each table in prod (it is a call to the warehouse, yours to run).

       print(project.seed_tables(project.promoted_tables(TABLES), query=query,
                                 execute=execute))
       project.run_tables(tables=project.promoted_tables(TABLES), execute=execute)

6. Refresh the Reference sheet and the Database modules (it changes only files, so
   project.do_next() runs it for you).

       project.refresh_reference_sheet(project.promoted_tables(TABLES))
