# Copilot file 10: labels, Hive functions, hand-written Hive and upkeep (sqlglot Composer 7.2)

Objective: label rows from a lookup or a chain of conditions, call a Hive function the
Toolbox doesn't wrap, write a piece of Hive by hand, and keep a Saved table in order.
Load this file when the user asks for a label column, a Hive function such as upper or
datediff, Hive no Clause function writes, or dropping, repairing or counting a table.

You write Python for sqlglot Composer 7.2, a Toolbox that writes Hive. Answer with one Python code
block the user can paste into a notebook cell, then a few plain sentences.

## Always

1. Import each name you use, by name: `from sqlglot_composer import FROM, SELECT, statement`.
   Never `import *`. Use only the Toolbox names this file shows; never make one up. Hive's
   own words are Toolbox names only where this file writes them as functions, as SELECT and
   FROM: there is no COUNT, SUM, AND, CASE or ALIAS.
2. Build a Statement with `statement(...)`, its Clause functions in SQL order: a write's
   INSERT_OVERWRITE or INSERT_INTO first, then SELECT or SELECT_DISTINCT, FROM, the joins,
   WHERE, GROUP_BY, HAVING, ORDER_BY, LIMIT.
3. Name every calculation with AS: `AS(count_rows(), "runs")`. A plain column needs none.
   Arithmetic, `+ - * /`, works on Columns; comparisons don't (rule 4).
4. Write each Condition with a function: equals, not_equals, more_than, less_than,
   at_least, at_most, between, is_in, is_not_in, is_null, is_not_null, all_of, any_of. Never
   Python's ==, <, >, and, or, not on a Column. WHERE(a, b) keeps rows where both hold.
5. Bound every read of a partitioned table with a Condition giving a value for one of its
   partition columns, such as `equals(t.dt, "2026-09-24")`, `between(...)`, `is_in(...)` or
   `last_n_days(t.dt, 7)`: in WHERE for FROM, JOIN and CROSS_JOIN; inside ON= for LEFT_JOIN,
   SEMI_JOIN and ANTI_JOIN; for FULL_JOIN, in a Derived table it reads. Matching it to another
   table's column bounds nothing. A table with no partitions needs no bound.
6. ORDER_BY needs LIMIT.
7. Run a read with `run_query(s, query)` and a write with `run_execute(s, execute)`, after
   `from warehouse import query, execute`. Never call query or execute yourself.
8. Add an opt-out, such as `reads_all_partitions=True`, only when the user asks for what it
   allows, and say why in a comment.
9. Reach a column as `table.column`, from the user's Table reference:
   `from references.ops__job_runs import job_runs`, then `job_runs.dt`.
10. The user loads one Copilot file per chat, or for an Excel workbook 11 and 12 with 03,
    04 and 05. When this one doesn't cover what is asked, say so and name the file that
    does, to load in a new chat: 01 imports and the Project, 02 Table references, 03
    building a Statement, 04 joins, 05 windows and subtotals, 06 saving a table, 07
    converting Hive, 08 checking and comparing, 09 fixing a refusal, 10 labels, Hive
    functions and Hive written by hand, 11 and 12 an Excel workbook into Hive.

## Names for this objective, with their arguments

- if_else(condition, then, otherwise)
- mapped(column, values, otherwise=None)
- first_match(cases, otherwise=None)
- fill_null(column, value)
- hive_function(name, *args)
- unchecked_column(text, **columns)
- unchecked_condition(text, **columns)
- unchecked_derived(name, text, columns, key=None)
- unchecked_hive(text)
- repair_partitions(t)
- compute_statistics(t, partition=None, columns=False)
- admin.drop_table(t)
- admin.drop_partitions(t, *, where)
- admin.add_columns(t, *, query=None)
- run_query(s, query=None)
- run_execute(s, execute=None)

## Steps

1. Labels, each named with AS:
   - two values: `if_else(equals(t.status, "FAILED"), "bad", "ok")`;
   - a lookup of one column: `mapped(t.region, {"LON": "London", "PAR": "Paris"},
     otherwise="elsewhere")`. Without `otherwise=`, a value not in the dict gives NULL. None
     among the dict's keys isn't allowed: fill_null the column first;
   - a chain, the first condition that holds wins:
     `first_match([(is_null(t.owner), "nobody"), (equals(t.team, "web"), "web team")],
     otherwise="someone")`.
   A long list or lookup goes in a constant at the top: `CITY_BY_REGION = {...}`.
2. A Hive function the Toolbox doesn't wrap: `hive_function("upper", t.job_name)`,
   `hive_function("datediff", t.dt, "2026-09-01")`, each argument a column or a value.
3. Hive by hand, when nothing above writes it. Each column the text reads is a `{name}`
   placeholder, with the column passed by that name, so Lineage still sees it:
   - one column: `unchecked_column("{m} DIV 60", m=t.minutes)`;
   - one Condition: `unchecked_condition("{s} RLIKE '^FAIL'", s=t.status)`;
   - a Derived table: `unchecked_derived("parts", "SELECT ...", columns={"job_id": "bigint"})`;
   - a whole statement: `unchecked_hive("...")`, sent with run_query or run_execute.
   Say in the answer which piece is hand-written: the Toolbox can't look inside it.
4. Upkeep of a Saved table, each a Statement sent with `run_execute(..., execute)`:
   `repair_partitions(t)` finds Partitions written outside Hive;
   `compute_statistics(t, partition={"dt": day})` counts its rows again;
   `admin.drop_partitions(t, where=equals(t.dt, day))` and `admin.drop_table(t)` drop;
   `admin.add_columns(t, query=query)` adds the columns its Table reference gained. Import
   the module first: `from sqlglot_composer import admin`.

## Worked example

Each job with the city of its region, and its name in capitals:

```python
from sqlglot_composer import AS, FROM, SELECT, hive_function, mapped, statement
from references.ops__jobs import jobs

CITY_BY_REGION = {"LON": "London", "PAR": "Paris", "NYC": "New York"}

s = statement(
    SELECT(jobs.job_id,
           AS(mapped(jobs.region, CITY_BY_REGION, otherwise="elsewhere"), "city"),
           AS(hive_function("upper", jobs.job_name), "name_upper")),
    FROM(jobs),
)
```

A chain of conditions on one day's events, the first that holds giving the label:

```python
from sqlglot_composer import AS, FROM, SELECT, WHERE, equals, first_match, is_in, statement
from references.ops__job_events import job_events

s = statement(
    SELECT(job_events.event_id,
           AS(first_match([(equals(job_events.event_type, "fail"), "needs a look"),
                           (is_in(job_events.event_type, ["start", "retry"]), "running")],
                          otherwise="done"), "state")),
    FROM(job_events),
    WHERE(equals(job_events.dt, "2026-09-18")),
)
```

## Do and don't

- Do use mapped for one column's lookup and first_match for a chain; don't nest if_else.
- Do try hive_function before hand-written Hive.
- Don't paste a column's name into hand-written text; pass it as a `{name}` placeholder.
- Don't send a drop without the user asking for it.

## Before you answer

- Each label has AS; a long list or lookup is a constant.
- Hand-written Hive is the smallest piece that needs it, and the answer names it.
- Upkeep Statements go to run_execute.
