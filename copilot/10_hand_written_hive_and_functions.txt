## Terms

- **Label**: a column whose value a lookup or a Condition, a test on rows, picks.
- **Hand-written Hive**: Hive text kept as written, `unchecked_...`: no Guard, which refuses
  a wrong result, looks inside it. **Lineage**: which columns feed each output column.
- **Saved table**: a table of the user's; a **Partition**, the rows sharing one value of a
  partition column.

## Rules

- **R1** Two values: `if_else(equals(t.status, "FAILED"), "bad", "ok")`.
- **R2** A lookup of one column: `mapped(t.region, {"LON": "London"}, otherwise="elsewhere")`:
  each key a value the column holds, each value its label. Without `otherwise=`, a value not
  in the dict gives NULL. None is no key: fill_null the column first.
- **R3** A chain, the first condition that holds winning: `first_match([(cond, label),
  ...], otherwise=...)`, conditions in the user's order; never a nested if_else.
- **R4** A long list or lookup is a constant at the top: `CITY_BY_REGION = {...}`.
- **R5** A Hive function with no Toolbox name: `hive_function("upper", t.job_name)`,
  `hive_function("datediff", t.dt, "2026-09-01")`, each argument a column or a value.
- **R6** By hand, the smallest piece, each column it reads a `{name}` placeholder passed by
  that name, so Lineage sees it; a value is written as Hive writes it, `'FAILED'` or `60`:
  `unchecked_column("{m} DIV 60", m=t.minutes)`; `unchecked_condition("{s} RLIKE '^FAIL'",
  s=t.status)`; `unchecked_derived("parts", "SELECT ...", columns={"job_id": "bigint"})`,
  read as a table; `unchecked_hive("...")`, sent with run_query or run_execute.
- **R7** `${hivevar:x}` is Hive as written, never a placeholder. A Script tag left as a
  Hivevar is answered `hivevar(...)` (files 07 and 17); a day worked out when the Hive is
  built is a Run value, written in by `hive_date(day)` (file 17).
- **R8** Upkeep, each sent with `run_execute(..., execute)`, after `from sqlglot_composer
  import admin`: `repair_partitions(t)` finds Partitions written outside Hive;
  `compute_statistics(t, partition={"dt": day})` counts rows again;
  `admin.drop_partitions(t, where=equals(t.dt, day))` and `admin.drop_table(t)` drop, only
  when asked; `admin.add_columns(t, query=query)` adds the columns its reference gained.
  Show each first with `show_hive(change)`; file 14's change_a_saved_table Workflow takes
  one through as a whole job.

## Always: rules A1 to A10

- **A1** Import each name you use, by name: `from sqlglot_composer import FROM, SELECT,
  statement`, never `import *`. Write only Toolbox names this file or the user's code shows:
  there is no COUNT, SUM, AND, CASE or ALIAS function.
- **A2** One `statement(...)`, its Clause functions in SQL order: a write's INSERT_OVERWRITE
  or INSERT_INTO first, then SELECT or SELECT_DISTINCT, FROM, the joins, WHERE, GROUP_BY,
  HAVING, ORDER_BY, LIMIT.
- **A3** Name every calculation with AS: `AS(count_rows(), "runs")`; a plain column needs
  none. `+ - * /` work on Columns; comparisons are A4's.
- **A4** Write each Condition with a function, never Python's ==, <, >, and, or, not on a
  Column: equals, not_equals, more_than, less_than, at_least, at_most, between, is_in,
  is_not_in, is_null, is_not_null, all_of, any_of. WHERE(a, b) keeps rows where both hold.
- **A5** **Bound every read of a partitioned table** with a value for one of its partition
  columns, such as `equals(t.dt, "2026-09-24")`, `between(...)`, `is_in(...)` or
  `last_n_days(t.dt, 7)`: in WHERE for FROM, JOIN and CROSS_JOIN; inside ON= for LEFT_JOIN,
  SEMI_JOIN and ANTI_JOIN; for FULL_JOIN, in a Derived table it reads. Matching it to another
  table's column bounds nothing. A table with no partitions needs no bound.
- **A6** Give every ORDER_BY a LIMIT.
- **A7** Run a read with `run_query(s, query)` and a write with `run_execute(s, execute)`,
  after `from warehouse import query, execute`. Never call query or execute yourself.
- **A8** Add an opt-out, such as `reads_all_partitions=True`, only when the user asks for
  what it allows, and say why in a comment.
- **A9** Reach a column as `table.column`, from the user's Table reference:
  `from references.ops__job_runs import job_runs`, then `job_runs.dt`.
- **A10** If this file doesn't cover the request, say so and name the file to load in a new
  chat: 01 the Project, 02 Table references, 03 a Statement, 04 joins, 05 windows and
  subtotals, 06 saving a table, 07 converting Hive, 08 checks, 09 a refusal, 10 labels and
  Hive by hand, 13 convert, 14 new tables and upkeep, 16 promote, 17 Run values and seeds, 18
  a Scheduled run, 19 a Metric request; an Excel workbook, 15 with 11 and 12.

## Worked patterns

### W1: each job with the city of its region, and its name in capitals

```python
from sqlglot_composer import AS, FROM, SELECT, hive_function, mapped, statement
from references.ops__jobs import jobs

CITY_BY_REGION = {"LON": "London", "PAR": "Paris", "NYC": "New York"}

s = statement(
    SELECT(jobs.job_id,
           AS(mapped(jobs.region, CITY_BY_REGION, otherwise="elsewhere"), "city"),
           AS(hive_function("upper", jobs.job_name), "name_upper")),
    FROM(jobs),
)
```

### W2: a chain of conditions, the first that holds giving the label

```python
from sqlglot_composer import AS, FROM, SELECT, WHERE, equals, first_match, is_in, statement
from references.ops__job_events import job_events

s = statement(
    SELECT(job_events.event_id,
           AS(first_match([(equals(job_events.event_type, "fail"), "needs a look"),
                           (is_in(job_events.event_type, ["start", "retry"]), "running")],
                          otherwise="done"), "state")),
    FROM(job_events),
    WHERE(equals(job_events.dt, "2026-09-18")),
)
```
