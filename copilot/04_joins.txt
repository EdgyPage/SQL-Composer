## Terms

- **Statement**: one Hive query, `statement(...)`; a **Condition**, a test on rows:
  `equals(...)`.
- `t`, `other`: two tables, as their Table references describe them: `job_runs`, `jobs`.
- **Key**: the columns that tell one row from another, from the Table reference.
- **Derived table**: a named Statement, `derived(...)`, read like a table.

## Rules

- **R1** After FROM: `JOIN(other, ON=equals(other.job_id, t.job_id))`. ON= takes a
  Condition; several, with `all_of(...)`.
- **R2** Three or more tables: one JOIN after another, each ON= matching the table it brings
  in to one already there, each partitioned one bounded (R4).
- **R3** The same table twice, or two tables of one name: give one a second name,
  `o = AS(other, "o")`, then `o.job_id`.
- **R4** Each partitioned table needs its own bound with a value; `equals(other.dt, t.dt)`
  matches rows but bounds nothing. FROM and JOIN: in WHERE,
  `WHERE(equals(t.dt, day), equals(other.dt, day))`. LEFT_JOIN, SEMI_JOIN, ANTI_JOIN: inside
  ON=, `ON=all_of(equals(other.job_id, t.job_id), equals(other.dt, day))`.
- **R5** JOIN keeps rows matched in both; LEFT_JOIN every row of FROM's table, NULL where
  `other` has none; SEMI_JOIN FROM's matched rows, each once, no column of `other`. There is
  no RIGHT_JOIN. A JOIN with no ON= is refused.
- **R6** A WHERE on a LEFT_JOIN's table is refused, as it drops the unmatched rows: put that
  Condition in ON=. A count of matches after a LEFT_JOIN is `count_distinct(other.run_id)`,
  0 for none, where `count_rows()` gives 1.
- **R7** Join on the joined table's whole Key; on less, one row can match many and counts
  come out too big: join a Derived table of one row per value (W3). Opt-outs only if asked.

## Worked patterns

### W1: each run of a day with its job's name

```python
from sqlglot_composer import FROM, JOIN, SELECT, WHERE, equals, statement
from references.ops__job_runs import job_runs
from references.ops__jobs import jobs

s = statement(
    SELECT(job_runs.run_id, jobs.job_name, job_runs.status),
    FROM(job_runs),
    JOIN(jobs, ON=equals(jobs.job_id, job_runs.job_id)),
    WHERE(equals(job_runs.dt, "2026-09-24")),
)
```

### W2: every job, with its scheduler runs that day, 0 for none

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, LEFT_JOIN, SELECT, all_of, count_distinct,
                              equals, statement)
from references.ops__jobs import jobs
from references.ops__scheduler_runs import scheduler_runs

s = statement(
    SELECT(jobs.job_id, AS(count_distinct(scheduler_runs.run_id), "runs")),
    FROM(jobs),
    LEFT_JOIN(scheduler_runs, ON=all_of(equals(scheduler_runs.job_id, jobs.job_id),
                                        equals(scheduler_runs.dt, "2026-09-24"))),
    GROUP_BY(jobs.job_id),
)
```

### W3: each job's minutes, job_runs grouped to a row per job first

```python
from sqlglot_composer import (AS, FROM, GROUP_BY, JOIN, SELECT, WHERE, derived, equals,
                              statement, sum_of)
from references.ops__job_runs import job_runs
from references.ops__jobs import jobs

per_job = derived("per_job", statement(
    SELECT(job_runs.job_id, AS(sum_of(job_runs.duration_mins), "minutes")),
    FROM(job_runs),
    WHERE(equals(job_runs.dt, "2026-09-24")),
    GROUP_BY(job_runs.job_id),
))
s = statement(
    SELECT(jobs.job_name, per_job.minutes),
    FROM(jobs),
    JOIN(per_job, ON=equals(per_job.job_id, jobs.job_id)),
)
```
