## Answer

Built in the commit that resolves this ticket.

- `sql_composer/edition.py` (a shared file, still generated into spark_composer/ until ticket
  02) holds `FOLDER`, `PRODUCT`, `VERSION`, the plugged-in writing and engine, and one
  forwarder for each of the seven Edition functions the shared files call. `check_installed`

  after ticket 02.

  (`_stop` takes a `folder`). Using a forwarder before any Edition is plugged in is refused at
  call time with a RuntimeError.
- lineage reads the time, commit and version through `_now`, `scripts_commit` and `_version`;
  tables.py and running.py name `edition.FOLDER`; warn_at_callers_line skips every Toolbox
  folder.
